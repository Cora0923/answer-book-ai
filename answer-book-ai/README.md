# Answer-Book-AI 📖
> 语义驱动的答案之书网页智能体 | 本地离线运行，无需调用大模型API

## ✨ 项目介绍
本项目复刻实体《答案之书》的趣味体验，使用中文SBERT语义向量模型，**不是纯随机抽取句子**：读取用户提问，计算语义相似度，再结合可调随机度，从答案库挑选适配的回答。
附带简易情绪识别，针对焦虑、纠结、期待类问题匹配对应风格答案；支持中英双语切换、问答历史记录与记录导出。
> ⚠️ 本项目仅供娱乐，不构成任何医疗、金融、法律方面的现实决策建议。

## 🎯 功能清单
- 🧠 语义相似度匹配，根据问题含义推荐贴合答案
- 🎲 随机度滑块：0=最贴合问题，1=完全随机翻书效果
- 😶‍🌫️ 简易情绪识别，自动匹配对应风格文案
- 🌐 中英文双语答案库，侧边栏一键切换
- 📜 会话问答历史，支持一键导出 txt 文件保存记录
- 🛡️ 敏感词拦截，识别专业领域问题给出免责提示
- 🖥️ Streamlit 网页界面，浏览器直接打开使用

## 🛠️ 技术栈
- Python
- Streamlit（网页UI）
- uer/sbert-base-chinese-nli 中文语义向量模型
- PyTorch
- NumPy
- TextBlob（简易情感判断）
